# Support

Start with [QUICKSTART.md](QUICKSTART.md), the
[user-data guide](docs/USER_DATA_GUIDE.md), and
[troubleshooting](docs/TROUBLESHOOTING.md). Use the repository issue tracker
for reproducible public software or documentation defects. Include version,
Python/platform, command, sanitized configuration, expected behavior, observed
error, and a minimal synthetic reproduction.

Do not post private images, annotations, predictions, models, credentials,
review material, or absolute local paths. Security-sensitive reports follow
[SECURITY.md](SECURITY.md), not the public issue tracker.

Support covers the documented base and quick CPU surfaces plus the exact Linux
x86-64 NVIDIA `science-gpu` runtime. Access to research data/models,
scientific interpretation, institution-specific license decisions, other
GPU/toolkit combinations, GUI/YOLO environments, the historical CPU-only
canonical runtime, and exact paper-result reproduction are outside this
software support scope.
