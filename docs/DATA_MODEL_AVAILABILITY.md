# Data and model availability — rc9 R4 local candidate

The staged public repository includes COMPAG 1.9.4rc10 source and four startup files in `bundled-assets/`: the matching application wheel and checksum sidecar, the exact native r92 model ZIP, and the ZIP of ten author-selected original example photographs. A normal clone includes these files. Full project images, annotations, masks, features, predictions and review logs are outside this public package and would require a separate controlled peer-review delivery. No public URL, reviewer access, or repository tag has been verified.

The ten photos carry no labels and do not establish training adequacy or a paper audit set. `r92 sample` uses synthetic rows and is a software check, not an accuracy estimate. Genuine human review and independent biological evaluation remain separate. See `PUBLIC_PHOTO_MANIFEST.json` and `ASSET_LICENSES/PUBLIC_ASSET_SCOPE_EN.md` for exact selected assets and author terms.
