# Using your own images with COMPAG 1.9.4rc10

Start with [Start Here](../START_HERE_EN.md). Run `python3 start_compag.py` from the clone to open the local browser guide. It automatically checks the four files included in `bundled-assets/`. After installing COMPAG, upload one of your own JPG/PNG photos at the analysis step. The upload stays in your private local work folder. The guide creates a new work session outside the source repository, prepares the required tiles, runs the existing full-card pipeline, and opens the existing candidate reviewer in another browser tab.

Your images, scores, review decisions and newly trained models stay in the work folder you select. Reopen the browser guide with the same work folder to continue review or resume an interrupted analysis. Return to the guide after review to explicitly choose Operational or Paper protocol XGBoost training; the latest model can then be selected for another photo. Deleted, skipped and unreviewed candidates are excluded from the reviewed-decision training scope. Bulk acceptance copies model decisions and is recorded separately from individual inspection. Paper protocol rejects bulk-accepted rows and requires individually reviewed decisions from at least six distinct original photos and valid group-safe splits. New uploads have distinct saved names; older uploads stored under a shared `original.jpg` name require new sessions and reviews for paper-protocol grouping.

For exact file formats, lineage and advanced commands, see [FIRST_RUN_COMPLETE_ROUND_EN.md](../FIRST_RUN_COMPLETE_ROUND_EN.md). The optional existing YOLO segmentation model remains outside the public Release; the browser can attach it for detector boxes and confidences on a later photo, as described in [EXTERNAL_YOLO_SEGMENT_INTEGRATION_EN.md](../EXTERNAL_YOLO_SEGMENT_INTEGRATION_EN.md). This browser path does not retrain YOLO. A successful software run does not certify scientific accuracy on a new image collection.
