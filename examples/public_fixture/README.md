# Public synthetic fixture

This fixture was generated from scratch by
`tools/generate_public_example_fixture.py`. It contains six synthetic training
groups, one independent synthetic inference group, two CVAT point rows, and a
paired synthetic pending/reviewed CSV example for the review schema.
It contains no research image, crop, annotation, model output, or reviewer
material. The fixture content is licensed under CC BY 4.0.

The `assets/` directory contains only a notice. Run the documented
`assets fetch` command to acquire the registered files. Asset files are
verified before publication and are not bundled in the repository.
