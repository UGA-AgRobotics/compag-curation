# Retained paper source and controlled replay

COMPAG Curation 1.9.4rc10 / R5.4 is a versioned software companion containing
retained scientific source, documented release adaptations and the identified
native r92 asset. Author-created Python source here is MIT; documentation is
CC BY 4.0 under [LICENSES](../LICENSES.md). Third-party terms remain separate.

The repository supplies executable modular Python, not the private reviewer
dataset. `bundled-assets/` includes only the selected r92 model and ten photos,
plus the matching application wheel and sidecar. Those are not the complete
historical replay inputs. See [current replay instructions](CURRENT_REPLAY_EN.md),
[INPUT_CONTRACTS.json](INPUT_CONTRACTS.json) and [result map](PAPER_RESULT_MAP.csv).
Saved-score evaluation, new inference and historical training reconstruction
are separate claims. New COCO/Stop code did not produce the historical paper
results. Original numerical verifiers and their pins are preserved.
